# 中文版修改说明

本项目基于 SnlperStripes 的 [Claude Account Switcher](https://github.com/SnlperStripes/claude-account-switcher)，保留 [Apache 2.0 许可证](../LICENSE)和[原作者声明](../NOTICE)。

相对于上游，中文版的主要修改包括：

- 增加 Windows 中文账号管理窗口、应用图标、托盘菜单汉化、账号用量排序和窗口复用；退出托盘时关闭账号窗口。
- 调整新增账号与退出 Claude 的流程，降低尚未保存的登录状态丢失风险。
- 合并并汉化上游的会话续接功能。
- 将程序更新地址指向本项目，并调整 Windows 构建、测试和文档。

修改文件的具体内容，以及本项目移除的上游文件，可通过 Git 提交记录查看。后续参考上游功能时，请继续保留原作者署名和许可证。
